# Supplementary Experimental Data

[中文说明](README_zh.md)

This package contains the input instances and experimental results for the manuscript **Energy-efficient fuzzy hybrid flexible flowshop scheduling of ship traffic in inland hubs with stage skipping and serial batch processing facilities**.

| File | Description |
|---|---|
| `Instances_23.mat` | 20 test instances and 3 instances for parameter configuration. |
| `SmallScale_Instances_3.mat` | Three small instances with 4, 5, and 6 ships for model validation. |
| `model_validation_experiments_results.mat` | Gurobi and QWOA results for the three small instances. |
| `model_validation_experiments_summary.xlsx` | Summary of model-validation results. |
| `ablation_results_5instances_20runs_3variants_final.mat` | Ablation results: 5 instances, 3 algorithm variants, and 20 runs per combination. |
| `ablation_summary.xlsx` | Summary of ablation results, including HV and IGD. |
| `sensitivity_results.mat` | Parameter-sensitivity results: 13 configurations and 10 runs per configuration. |
| `sensitivity_summary.csv` | Parameter settings and HV values for the 130 sensitivity runs. |
| `Comparative_Experiments_results_20x20_5alg.mat` | Comparative results: 20 instances, 5 algorithms, and 20 runs per combination. |
| `Comparative_Experiments_Summary.xlsx` | Summary of comparative results, including performance metrics and statistical analysis. |

MAT files contain input data or saved experimental records. Excel and CSV files provide readable results and summaries.
